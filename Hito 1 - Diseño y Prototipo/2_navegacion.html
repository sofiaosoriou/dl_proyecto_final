Vistas públicas: Página principal, Registro e Inicio de sesión. Sin restricciones de acceso.
Modelo C2C: Un mismo usuario puede tener publicaciones activas como vendedor y al mismo tiempo comprar cafés de otros usuarios. No hay roles diferenciados en la plataforma.
Sesión en frontend: Al hacer login se guarda { token, user: { id, nombre, email, foto_url } }. El token se adjunta como Authorization: Bearer <token> en cada petición privada.
Restricción: Un usuario no puede comprar sus propias publicaciones. Esta validación se realiza en el backend comparando el user_id del vendedor con el del comprador.
